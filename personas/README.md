# 分身配方 —— 三份文件，给工作台里的 AI 一个魂

把下面三份 `.md` 填好，然后在工作台里：

> **设置 → AI 成员与模型 → 「⇪ 导入身份文件」** → 选中这几份 → 起个名字 → 完事。

它当场就成了一个**带人格、有记忆、能读写文件、能跑命令**的成员。

## 三份文件各写什么

| 文件 | 回答的问题 | 写坏了会怎样 |
|---|---|---|
| `IDENTITY.md` | 它是谁？ | 它会不知道自己叫什么、该用什么调性 |
| `SOUL.md` | 它怎么做事？ | 它会变成"一个搜索引擎加一张嘴" |
| `USER.md` | 它在跟谁说话？ | 它不会照顾你的习惯，每次都要你重复交代 |

三份都不是必填 —— 一个不填，就是个通用助手。文件不存在会被安静跳过，不会报错。

## 为什么这么设计

工作台每次开口前，会把这些文件的**全文**拼进系统提示里。所以它的性格不是"设了一个
人设词"，而是**每次真的读一遍这些文件**。

结论：**你改文件，它下次说话就变了。** 不用重启服务，不用重新训练。

## 想更省事

工作台里打开 **设置 → AI 成员与模型**，点某个成员的「编辑」，
左边「人设文件」那一栏就是你导入进来的这些文件的路径。
你可以随时再加一个自己的笔记文件进去（比如 `我的项目.md`），它也会照读。

## 相关

- 想让它用你自己的 CLI（DeepSeek Harness / Claude Code / 自写脚本）干活，
  看成员弹窗里的 **「工作引擎」**：选「外部命令」，填一条命令即可。
- 想改工作台的界面和回复方式，看 [`../plugins/README.md`](../plugins/README.md)。
